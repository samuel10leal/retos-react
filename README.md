# Retos React

Un solo proyecto con cuatro vistas. Usa la lista desplegable de arriba para cambiar de reto.

1. Navbar normal y reflejada.
2. Barra de progreso con porcentaje.
3. Formulario con validación y alert(JSON).
4. Timer con Start, Stop y Reset.

## Ejecutar

Abre esta carpeta en VS Code y ejecuta:

```bash
npm install
npm run dev
```

## Archivos

- src/App.jsx: lista desplegable para cambiar de vista.
- src/Reto1.jsx a src/Reto4.jsx: cada ejercicio.
- src/App.css: colores y estilos de los retos 1 y 2.

Al cambiar de vista se reinicia el reto que estabas viendo. El formulario simula el envío local; no conecta a una base de datos.

## Un solo repositorio en GitHub

Descomprime el ZIP, crea un repositorio llamado retos-react y usa Upload files para subir el contenido de esta carpeta, incluida src. No subas el ZIP ni node_modules. Pulsa Commit changes.
